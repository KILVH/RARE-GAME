SPB DRIFT: ЗАГРУЗКА НА GITHUB PAGES

1. Создай новый репозиторий на GitHub, например:
   spb-drift

2. Открой репозиторий -> Add file -> Upload files.

3. Загрузи ВСЕ содержимое папки SPB_Drift_build:
   index.html
   manifest.webmanifest
   sw.js
   start_game.bat (на GitHub не нужен, можно не загружать)
   maps/
   изображения меню
   машины/полицию
   и остальные файлы из архива.

   ВАЖНО: структура папок должна сохраниться.
   index.html должен лежать в КОРНЕ репозитория.

4. Нажми Commit changes.

5. Репозиторий -> Settings -> Pages.

6. В разделе Build and deployment:
   Source = Deploy from a branch
   Branch = main
   Folder = / (root)

7. Нажми Save.

8. GitHub выдаст адрес вида:
   https://ТВОЙ-ЛОГИН.github.io/spb-drift/

9. Открывай именно этот адрес. Через несколько минут изменения появятся.

МОБИЛЬНОЕ УПРАВЛЕНИЕ

- На телефоне игра рассчитана на горизонтальный режим.
- Если телефон вертикально, появляется сообщение «Поверни телефон горизонтально».
- Сенсорные кнопки:
  ◀ ▶ = руль
  ГАЗ = газ
  ТОРМОЗ = тормоз
- НАКЛОН: ВКЛ = управление рулём гироскопом.
- КАЛИБРОВКА = текущее положение телефона становится прямым рулём.
- На iPhone при первом включении наклона браузер может попросить разрешение на датчики.
- Игра пытается включить landscape через Screen Orientation API, но браузер может разрешить принудительную блокировку только после жеста пользователя. Поэтому экран «Поверни телефон» остаётся резервным и гарантированно работает.

PWA

manifest.webmanifest и sw.js уже добавлены.
На поддерживаемых браузерах игру можно добавить на главный экран. GitHub Pages работает по HTTPS, что важно для датчиков и PWA.

ЕСЛИ ПОСЛЕ ОБНОВЛЕНИЯ ВИДНА СТАРАЯ ВЕРСИЯ
- Открой сайт в приватной вкладке.
- Либо очисти данные сайта.
- Service Worker может держать старый кэш. После первого обновления подожди и перезагрузи страницу.

ЛОКАЛЬНО
start_game.bat нужен только для запуска на компьютере. На GitHub он не нужен.
